COMPANION INTEGRATION QA

A small friend in the navigation.

This page embeds a minimized companion in a sample reader header. It shares only the isolated QA save with the scenario page.

Dock and modal checks

  1. Open the room using the companion button in the header.
  2. Use the room tabs, open a treat dialog, and return to the room.
  3. Close the room with its minimize button or Escape. Focus should return to the dock.
  4. Resize the browser or use a mobile viewport. The room should stay usable and scroll within the modal.

The component has dock-position="inline" and no expanded attribute.

Sample reader content stays in place while the companion opens above it.
